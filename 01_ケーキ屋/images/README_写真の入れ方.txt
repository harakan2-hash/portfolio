【サンタプレ サイト｜写真の入れ方】

この images フォルダに、下記のファイル名で写真を保存するだけで、
サイトに自動で反映されます（写真が無い間は仮のイメージ画像が表示されます）。

Instagram（@santapule.cake）に上げている元写真を、そのまま使えます。
スマホから保存 → このフォルダに入れて、ファイル名を下記に合わせてください。

────────────────────────────────
◆ 必ず欲しい写真（優先度：高）
────────────────────────────────
hero.jpg            … トップの大きな背景写真（店内 or ケーキの引きの写真／横長がおすすめ）
wagahai-roll.jpg    … 看板商品「我輩ロール」の写真
concept.jpg         … コンセプト欄用（作っている様子 or 店の雰囲気）
shop-shiroyama.jpg  … 城山本店の外観
shop-kamikumamoto.jpg … 上熊本店の外観

────────────────────────────────
◆ メニュー写真（あれば）
────────────────────────────────
menu-matcha.jpg     … 抹茶んロール
menu-shiroyama.jpg  … 城山ロール
menu-chocolat.jpg   … ショコラ
menu-cheese.jpg     … ニューヨークチーズケーキ
menu-tart.jpg       … 季節のタルト
menu-croissant.jpg  … クロワッサン／カヌレ

────────────────────────────────
◆ ギャラリー＆インスタ欄（あれば／枚数自由）
────────────────────────────────
gallery-1.jpg 〜 gallery-8.jpg
insta-1.jpg 〜 insta-6.jpg

※ 店頭ポップの写真を1枚ずつ切り抜いたものでOKです。元のポップ画像をこのフォルダに置いてもらえれば、Claude側で6枚に自動で切り出せます。

※ 拡張子は .jpg 推奨。.png や .jpeg の場合は index.html 側で拡張子を合わせます（ご相談ください）。
※ 縦横比はこちらで自動調整するので、そのままの写真でOKです。
